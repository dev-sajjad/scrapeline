Live events

Every step of the platform writes an event: a run starts, records are loaded, quality checks finish, a run succeeds or fails. This page shows the latest {{ replay_limit }} events that match the filters, then adds new ones at the top as they happen.

What the events mean
run.started, run.finished, run.failed
A run of a source began, succeeded or failed. A failed run carries the error as its message.
records.loaded
Validated records were written. The data counts inserts, updates, unchanged rows and removals.
checks.done
Quality checks ran after a load. Level warning or error means at least one check did not pass.
site.classified
A site got a category, from the classifier or from a person.
Levels
debug, info, warning and error. Choose a minimum level to hide routine events.
Kind prefix
run matches every run.* event; run.failed matches only that kind.
