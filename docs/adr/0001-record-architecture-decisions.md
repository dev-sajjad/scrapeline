# ADR-0001: Record architecture decisions

Status: accepted · Date: 2026-11-13

## Context
This project is a production-grade scraper platform. Every design choice must answer "why X and not Y". Decisions made in chat or in a head are lost.

## Decision
Every non-trivial technology or design choice gets one ADR in `docs/adr/`, numbered, with Context, Decision, Alternatives, Consequences. ADRs are never edited after acceptance; a new ADR supersedes an old one.

## Consequences
Slower to decide, faster to explain. The README links the ADR index.
